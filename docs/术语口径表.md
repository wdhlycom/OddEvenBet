## 一、四个"不要加注解"的情况（硬规则）

1. **文章这一句正在解释这个词**——句子本身已经写了"强队让弱队分数"这类定义，就不要再套一次注解（重复解释是败笔）。
2. **术语表已收录的通用词**——见 `zh-shuyu-biao.md`（独赢、让分、大小分、滚球这些通用盘口词），正文可不加或只加一次。
3. **同篇重复出现**——只在第一次出现时加。
4. **母语读者不可能不懂的词**——篮球、进球、比分、冠军这类，不加。

## 二、术语分级与标准写法

### 注解标准格式（一句话，口语，先说"是什么"再说"对下注意味着什么"）

```
术语 = 一句话定义 + （对下注意味着什么）
```

---

### A 类 · 盘口术语（每项运动独特的"下注方式"，小白最看不懂，必加）

| 术语 | 所属运动 | 建议解释 |
|---|---|---|
| 让分 / 点差 | 篮球、美式足球 | 给强队减分、弱队加分后再比谁赢，把强弱悬殊的比赛拉成五五开。 |
| 总分 / 大小分 | 通用 | 押两队总得分比一个数大还是小，不押谁赢，押"进多少"。 |
| 独赢 / moneyline | 通用 | 最简单，只押谁赢，不管赢多少。 |
| 滚球 / live | 通用 | 比赛开打后还在下注，盘口跟着比分实时变。 |
| puck line | 冰球 | 冰球的让分盘，几乎固定让 1.5 球。冰球进球少，1.5 球已是很大差距。 |
| run line | 棒球 | 棒球的让分盘，通常让 1.5 分。 |
| 亚洲盘 / 让球 | 足球 | 给强队一个"负担"让比赛变五五开；整数盘可能走水退款，带 0.5 的不走水。 |
| 1X2 | 足球 | 1=主胜、X=平、2=客胜，足球最基本的三种结果。 |
| 回合盘 | 格斗 | 押比赛会不会打满某个回合，依赖选手"速战还是磨满全场"的风格。 |
| 获胜方式 | 格斗 | KO/TKO、降服、判定三选一，MMA 独有、信息量最大的盘。 |
| 地图胜负 | 电竞 | 押单张地图胜负，变数比整场大。 |
| 让局 / 让盘 | 网球、飞镖、斯诺克 | 强手让弱手几局/几盘，押能不能赢过这个让分。 |
| 总局数 | 网球 | 押整场总局数大于还是小于某个数。 |
| 总 180 | 飞镖 | 押全场打出几个"180分"（单轮最高分），更接近彩蛋。 |
| 最高收尾 | 飞镖 | 押谁打出的收尾分最高，好玩但不必下重注。 |
| 单杆最高 | 斯诺克 | 押全场谁打出单杆最高分。 |
| 总破百 | 斯诺克 | 押全场打出几个"破百"（单杆 100 分以上）。 |

### C 类 · 该运动独特概念（体育小白真正卡壳的地方，必加）

| 术语 | 所属运动 | 建议解释 |
|---|---|---|
| 守门员（冰球语境） | 冰球 | 冰球最关键的位置，状态热起来能单场扑 40 次射门，决定比赛。 |
| 空门进球 | 冰球 | 落后方最后撤下守门员多上一名球员，常被打空门，1 分领先变 2 分。 |
| 加时 / 点球大战 | 冰球、足球 | 常规时间打平后的决胜方式，分清自己买的是"含加时"还是"不含加时"。 |
| 缠斗型 / 站立型 | 格斗 | MMA 最基础判断：靠地面降服 vs 靠拳腿 KO，风格克制比名气重要。 |
| 减重 / 称重 | 格斗 | 赛前一天称重达标，减重失败会明显乏力，直接毁掉技术分析。 |
| toss（掷硬币） | 板球 | 赛前掷硬币定谁先攻，某些场地先攻优势巨大。 |
| pitch（板球场地） | 板球 | 不同球场草皮硬度湿度不同，决定是打手友好还是投手友好。 |
| 场地类型（硬地/红土/草地） | 网球 | 球速和回合差异大，同一选手在不同场地表现天差地别。 |

## 三、下一步：深化各项目（按博彩体量优先级）

优先级：**足球 > 篮球(NBA) > 电竞 > 美式足球(NFL) > UFC > 板球 > 网球 > F1**

每篇要补齐冰球范例那套"血肉"：

1. **赛事背景**：这是什么运动、一场比赛怎么打、全球哪里流行、体量多大。
2. **赛季/时间节奏**：什么时候有球、赛程怎么排、哪个阶段下注价值最高。
3. **强队/代表人物（带故事）**：3–5 个，每个一句"故事化记忆点"。
4. **核心盘口**（已有，保留）。
5. **关键变量**（已有，保留 + 可加术语注解）。
6. **博彩体量数据**：Polymarket / 行业公开数据，证明"为什么值得下注"。
